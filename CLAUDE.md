# Правила работы в проекте

## Прод — только чтение

Боевая база (Upstash из `.env`) и продовые вебхуки не трогаются без явного
разрешения Ивана в этой сессии — даже если потом убрать следы.

- **Нельзя без разрешения:** записывать в боевую базу тестовые данные
  (пользователей, сессии, заявки, поиски) и слать подставные запросы
  в `https://peresmenka.vercel.app/api/tg/webhook/` или любой другой маршрут
  прода, который пишет в базу.
- **Можно:** проверять прод чтением — статусы ответов, заголовки, содержимое
  страниц, консоль браузера. Запрос, который ничего не пишет (например, выход
  без сессии), — тоже чтение.
- **Всё, что пишет в базу, проверяется локально или на предпросмотре.**
  Локально: `npm run serve` без ключей или сценарии `npm run test:ui` —
  обвязка `test/ui/harness.mjs` поднимает сайт с пустыми ключами Upstash
  и Telegram и тестовым секретом вебхука, хранилище живёт в памяти.
  Вход в сценариях идёт через вебхук тестового сайта, а не прода.
- Секреты из `.env` не выводить в консоль и не вставлять в ответы.
