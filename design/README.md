# Эталон

`reference.html` — макет, собранный заказчиком в Claude Design и принятый
как источник правды для визуального слоя. Это самораспаковывающийся бандл:
открывается в браузере как обычная страница, значения снимаются с неё через
`getComputedStyle`, распаковывать ничего не нужно.

Холст неподвижный, 1440 × 2600, только главная. Всё остальное — телефон,
страница группы, статические страницы, кабинет, пустые состояния — решено
в том же языке, но в эталоне этого не было.

Чего из эталона нет на сайте и почему — в README проекта, раздел
«Цвет и графика».
